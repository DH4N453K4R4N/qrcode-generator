# QR Code Generator

A **minimalist and responsive QR Code Generator** with customizable colors. Enter text or a URL, choose from 5 preset colors or a custom color picker, generate, and download QR codes instantly.

## Features

- Responsive and mobile-friendly design  
- 5 preset color swatches + custom color picker  
- Generate QR codes with your chosen color  
- Download QR codes as PNG  

## Usage

1. Open `https://dh4n453k4r4n.github.io/qrcode-generator/` in your browser.  
2. Enter the text or URL.  
3. Select a color or use the custom color picker.  
4. Click **Generate** to create the QR code.  
5. Click **Download** to save the QR code.  

## Built With

- HTML5  
- CSS3  
- JavaScript (QRCode.js)
